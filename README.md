# StoreAlfabet

Mobil PWA for 1. og 2. klasse. Hunden heter Alf. Alf har forsovet seg og må rekke skolen. Barnet løser bokstavoppgaver, samler krystaller og diamanter, og kan møte klønete bokstav-zombier. Målet er å kjøpe best mulig skolemelk.

## Bruk

Publiseres med GitHub Actions til GitHub Pages. Barnet åpner siden og legger den til hjemskjermen.

- Android: nettleseren kan vise «Legg til på startskjermen»
- iPhone: Del → Legg til på Hjem-skjerm

Utvikling:

```powershell
npm install
npm test
npm run dev
```

Bygg:

```powershell
npm run build
npm run preview
```

## Meny

Spill, Innstillinger (nivå, lyd og Alfs skolesekk), Rekord og Om appen. Alt på bokmål. Hjemskjerm-navnet er StoreAlfabet.
